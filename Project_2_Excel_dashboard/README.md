# UPI Spending Pattern Dashboard

An interactive Excel spreadsheet dashboard analyzing transaction spend distributions across merchant categories and monthly timelines.

## What I Did
1. **Data Structuring & Clean-up:** Organised raw payment records into structured Excel tables and checked for missing attributes.
2. **Pivot Table Aggregations:** Created summary tables to aggregate total transaction spend, transaction counts, and category proportions.
3. **Data Modeling & Formulas:** Used dynamic lookup formulas (`XLOOKUP` / `VLOOKUP`) and conditional formatting to highlight peak spending categories.
4. **Interactive Visualization:** Built category distribution charts and monthly trend lines to visualize spending patterns clearly.

## File Included
* `UPI_Spending_Dashboard.xlsx` — Excel workbook containing raw data sheets, pivot table summaries, and visual dashboard charts.
